Owner Protection Rules
Owner নিজেকে delete করতে পারবে না।
Owner transfer করতে হলে second admin approval লাগবে।
Last active owner থাকলে family deactivate করা যাবে না।
Financial delete/void হলে audit_logs mandatory।

Offline-First + Sync Architecture
Internet ছাড়াও ১০০% কাজ করবে — sync হবে পরে
✅ মূল নিয়ম: User যা করুক — আগে SQLite-এ save হবে, UI তাৎক্ষণিক update হবে। Internet পেলে background-এ server-এ sync হবে। User কিছু বুঝবে না।

Double-Entry Accounting Engine
প্রতিটি transaction দুটি entry তৈরি করবে — Debit = Credit সবসময়
নিয়ম: প্রতিটি transaction-এ transaction_lines টেবিলে কমপক্ষে ২টি row তৈরি হবে। সব debit-এর যোগফল = সব credit-এর যোগফল। এই balance ভাঙলে transaction reject হবে।

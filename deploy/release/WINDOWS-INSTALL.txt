S4 Family Finance 143 — Windows install
=======================================

Normal software install (no Python; the app uses the VPS server):

1. Download S4-Family-Finance-143-Setup.exe from GitHub Releases
2. Double-click Setup → Next → Install → Finish
3. Open "S4 Family Finance 143" from Desktop or Start Menu
4. Sign in with your server account email + password (same as phone APK)

Sync with the VPS is automatic. No PC server or API URL needed.

Optional backup: Settings → Cloud → Google Drive / local folder.

S4 Family Finance 143 — PWA install
===================================

1. Open the live site: https://app.s4businessthinking.com
2. Android: Chrome → Menu → Install app
3. iPhone: Safari → Share → Add to Home Screen
4. Log in with your server account (or register), then create or join a family.

Data is stored on the VPS server; the app keeps an offline copy and syncs when online.
